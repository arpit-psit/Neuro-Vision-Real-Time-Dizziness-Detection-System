# Neuro-Vision-Real-Time-Dizziness-Detection-System
## 🚀 Key Features  * Real-time face and eye tracking using webcam * Eye Aspect Ratio (EAR)–based blink and drowsiness detection * Continuous monitoring of eye closure duration * Head movement and stability analysis * Emotion detection (stress, fatigue, confusion) using DeepFace * Instant alert system (sound or notification) * Lightweight
